## 7. 已知残余（S3 / follow-up，不阻断发布）

- **N4**：带嵌套括号默认参数的函数源码在 `wait{for:'function'}` 仍可能早通过（0.1.11 起既有）。
- **N6**：生成错误文案里 11 处硬编码 `~2400 ms`（轮询常数已提常量，但文案未引用）。
- **N7**：`typeof page.label === "string"` 是硬条件（非字符串 label 的 Page 会被判失败）。
- **N8**：dialog 错误前缀变更（`trigger click failed:` / `answering the dialog failed:`），外部全文匹配会失配。
- **N9**：成功路径的 `log` 仍可能接近 `maxOutputBytes`（与 `truncated:true` 配套，体积需注意）。
- **N2①**：Page 工具/tabs 的 `id` 优先于 name，而 `ego_app_space`/`open` 仍 name 优先——schema 措辞可按工具差异注明。
- **N2②**：Page 工具可显式传 `id:0` 命中用户空间（新可达面）。
