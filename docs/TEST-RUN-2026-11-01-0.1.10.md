实测行的关键样本：

- **quoted-CSS**：`mouse_click` 用 `[data-x="a>>b"]` → `selector not found: [data-x="a>>b"]`（被当作合法 CSS 去查，而不是被 `does not accept` 拒绝）。
- **pageCreated**：复用 `p1` → `{"pageCreated":false,"page":"p1"}`；请求 `p9` → `{"pageCreated":true,"page":"p4"}`。
- **js mode**：`expression` / `statements` / `function` 三种模式都返回 `42`；非法 mode → `unknown js mode "eval"; use one of auto | expression | statements | function.`。
- **wait function**：`() => false` + `timeoutMs:800` → `page.waitForFunction timed out after 800ms`（旧实现会立刻真值化通过）。
- **abort**：400 ms 后 abort 一个 30 s 的 wait → `{"ok":false,"elapsedMs":439,"error":"aborted by the caller"}`；调用前已 abort → `elapsedMs:0`。
- **timeout 卫生**：`navigate`/`wait`/`download`/`wait_control` 传 `0` 与 `-5` 都报同一条 `timeoutMs must be a positive number…`，且无副作用：`navigated:false`、`savedFileExists:false`、`wait_control elapsedMs:0`。
